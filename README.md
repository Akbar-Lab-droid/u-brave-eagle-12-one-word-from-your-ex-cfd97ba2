## Entry

The entry is exactly one word (1 to 24 characters): the word my ex would use to describe me. It lives in `entry.txt`.

## How to run

```sh
python3 main.py
```

`main.py` copies `entry.txt` to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `out/entry.txt`).
